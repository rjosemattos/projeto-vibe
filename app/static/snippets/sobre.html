O que é o Prompt Sanitizer?

O Prompt Sanitizer é uma ferramenta que analisa o texto de prompts de IA e remove informações sensíveis antes que elas sejam compartilhadas publicamente, adicionadas a um conjunto de dados ou enviadas para um serviço de terceiros.

Desenvolvedores, estudantes, pesquisadores e engenheiros de prompts frequentemente copiam e colam prompts de conversas reais em issues do GitHub, posts de blogs, conjuntos de dados ou discussões online — muitas vezes sem perceber que esses prompts ainda contêm informações sensíveis como chaves de API, endereços de e-mail, números de telefone ou strings de conexão com bancos de dados.

Por que a privacidade dos prompts é importante?

Ao interagir com um modelo de linguagem de grande escala (LLM) em um ambiente de produção, seus prompts podem conter dados reais da sua aplicação.

Um desenvolvedor testando um chatbot de atendimento ao cliente, por exemplo, pode inserir o e-mail real de um cliente. Um engenheiro depurando um pipeline de geração aumentada por recuperação (RAG) pode incluir resultados de consultas ao banco de dados contendo IDs de usuários ou números de telefone reais.

Esses cenários são mais comuns do que muitas equipes imaginam. O impacto não se limita a um constrangimento: pode resultar no comprometimento de uma chave de API, em uma violação de privacidade ou na exposição de informações de identificação pessoal (PII).

O que o Prompt Sanitizer detecta?

A ferramenta utiliza detecção baseada em padrões para identificar diferentes categorias de dados sensíveis:

  • Chaves de API e Tokens Detecta chaves da OpenAI, GitHub, Slack, AWS, Google e segredos alfanuméricos genéricos.
  • Endereços de E-mail Identifica padrões comuns de endereços de e-mail em diferentes domínios.
  • Números de Telefone Detecta formatos de números de telefone, incluindo hífens, pontos e parênteses.
  • URLs e Endpoints Identifica URLs HTTP e HTTPS, incluindo endpoints internos de APIs e servidores de desenvolvimento.
  • Endereços IP Detecta endereços IPv4 no formato decimal com pontos.
  • UUIDs e IDs Identifica UUIDs no formato padrão utilizados por bancos de dados e serviços em nuvem.
  • Tokens JWT Detecta JSON Web Tokens que começam com o cabeçalho padrão eyJ.
  • Números de Cartão de Crédito Identifica padrões comuns de números de 13 a 16 dígitos.
  • CPF e outros identificadores Identifica padrões de números de identificação pessoal.
  • Nomes Detecta expressões como "Meu nome é" ou "Pode me chamar de", seguidas por um nome.

Cada categoria pode ser ativada ou desativada individualmente, permitindo um controle preciso sobre o que será removido.

Como funcionam os placeholders de remoção?

Em vez de simplesmente excluir os valores detectados, a ferramenta os substitui por placeholders identificados, como:

[API_KEY_REDACTED] [EMAIL_REDACTED]
  • Preserva a estrutura e a intenção do prompt — permite entender que havia uma informação naquele local.
  • Facilita a auditoria — permite revisar o resultado e verificar se a remoção foi correta.
  • Mantém a coerência dos conjuntos de dados — exemplos continuam demonstrando o padrão da conversa sem expor os dados reais.
  • Cria um registro claro da sanitização — permite identificar qual tipo de informação foi removida.

Sanitização de prompts para conjuntos de dados de IA

Um dos principais usos dessa ferramenta é a limpeza de conjuntos de dados utilizados para fine-tuning e avaliação de modelos antes de sua publicação.

Ao desenvolver um LLM personalizado ou realizar fine-tuning de um modelo existente com dados de conversas proprietárias, seu conjunto de treinamento pode conter interações reais de usuários.

O Prompt Sanitizer torna esse processo mais rápido: basta inserir cada trecho da conversa, realizar a sanitização e copiar a versão limpa.

Em pipelines de larga escala, os mesmos padrões utilizados pela ferramenta podem ser adaptados para scripts em Python ou Node.js, permitindo o processamento em lote.

Limitações e boas práticas

A detecção baseada em padrões é rápida e eficiente para formatos conhecidos, mas não é infalível.

  • Formatos não convencionais — alguns segredos podem não ser identificados caso estejam em formatos incomuns.
  • Nomes em contextos diferentes — um nome isolado no meio de um parágrafo pode não ser identificado.
  • Informações que dependem de contexto — nomes internos de projetos, terminologias proprietárias ou códigos específicos de uma empresa podem não ser detectados.
Boa prática: utilize a ferramenta como uma primeira camada de verificação automatizada e realize uma revisão manual do resultado antes de publicá-lo.

Baseado no navegador e com foco em privacidade

O Prompt Sanitizer funciona inteiramente no lado do cliente. O texto do seu prompt é processado pelo JavaScript diretamente no navegador e não é enviado para nenhum servidor externo.

Isso é especialmente importante porque o objetivo da ferramenta é justamente lidar com informações sensíveis — seria contraditório enviar esses dados pela internet para realizar a sanitização.

Seus dados permanecem no seu navegador.

Não há necessidade de criar uma conta, não armazenamos logs e não realizamos análises sobre os seus prompts.
